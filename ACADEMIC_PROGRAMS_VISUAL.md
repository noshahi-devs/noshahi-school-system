## User Journey by Device

### Desktop User
1. Opens page
2. Sees full table immediately
3. Reads all information at once
4. No scrolling needed
5. Complete view of all educational levels

### Tablet User (Landscape)
1. Opens page
2. Sees full table (usually)
3. Reads information clearly
4. May scroll on portrait mode
5. Good readability

### Mobile User (480px)
1. Opens page
2. Sees first column (Level)
3. Realizes more columns available
4. Scrolls right to view details
5. Sees Grade, Age, Program, Features
6. Can scroll to see different rows

### Small Phone User (360px)
1. Opens page
2. Sees first column
3. Must scroll to see other columns
4. Reads content in sections
5. Ultra-compact but readable
6. All info accessible
