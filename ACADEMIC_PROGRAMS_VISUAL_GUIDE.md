## Horizontal Scroll Behavior

### How It Works

**Step 1: Container Overflow**
```
Content Width (550px+) > Container Width (480px) = SCROLL
```

**Step 2: User Action**
```
Desktop: Can see all (no scroll)
Tablet:  Can scroll right to see more
Mobile:  Must scroll right to see all columns
```

**Step 3: Smooth Scrolling**
```
.programs-overview-wrapper {
  overflow-x: auto;
  -webkit-overflow-scrolling: touch;  ← Enables smooth momentum
}
```

### User Experience

**What User Sees**:
```
Initial View:
[Level] [Grade] [Age] [Program] [→ Scroll to see Features]
 
After Scrolling Right:
[Grade] [Age] [Program] [Special Features] [→ Continue scroll]
```
