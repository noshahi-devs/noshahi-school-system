📝 NOTES FOR DEVELOPERS

Key Points:
  1. All responsive logic is CSS-based (no JavaScript)
  2. Images use 'object-fit: cover' for consistent aspect ratio
  3. Button behavior changes at 768px breakpoint (becomes full-width)
  4. Feature lists have reduced gap on mobile (0.7rem vs 0.8rem)
  5. Image wrapper height is the primary responsive control

Customization Guide:
  • To change breakpoints: Update @media query values
  • To adjust colors: Modify .program-content-badge and button colors
  • To resize images: Change .program-image-wrapper height values
  • To modify fonts: Update heading/text font-size values
  • To add effects: Extend .program-cta-btn or .program-image-wrapper

Common Tasks:
  • Add new breakpoint: Copy @media block and adjust values
  • Change color scheme: Update background and button gradients
  • Adjust spacing: Modify padding and margin values
  • Update images: Keep same aspect ratio, responsive height

📞 QUICK TROUBLESHOOTING

Issue: Layout not responsive
  Solution: Check viewport meta tag, clear cache, reload page

Issue: Images appear distorted
  Solution: Verify object-fit: cover is applied, check image dimensions

Issue: Colors don't match design
  Solution: Check .islamic-program-section class is applied correctly

Issue: Buttons not full-width on mobile
  Solution: Verify media query breakpoint (768px) is triggering

Issue: Text too small on mobile
  Solution: Check font-size values in mobile breakpoints

Issue: Spacing looks wrong
  Solution: Review padding/margin values, compare with VISUAL_GUIDE.md
