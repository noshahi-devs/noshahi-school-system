## Spacing & Layout Details

### Programs Grid
```
Before:
├─ minmax: 350px
├─ gap: 2rem
└─ Results: خالی space زیادہ

After (OPTIMIZED):
├─ minmax: 320px ✓ (کم space)
├─ gap: 1.75rem ✓ (compact)
└─ Results: Cards wider, better fit
```

### Specialized Grid
```
Before:
├─ auto-fit (3 cards)
├─ minmax: 340px
└─ Results: Science card بھی تھا

After (OPTIMIZED):
├─ fixed 2 columns
├─ max-width: 900px
├─ margin: 0 auto ✓ (centered)
└─ Results: Perfect balance
```

### Section Spacing
```
Desktop:
├─ Programs padding: 4rem 0 (was 5rem)
├─ Additional margin: 3.5rem top (was 5rem)
├─ Additional padding: 2rem top (was 3rem)
└─ Title margin: 2.5rem bottom (was 3rem)

Result: Section ایک viewport میں ہے ✓
```

```

      ↓

      ↓

      ↓

      ↓

      ↓
Result: Beautiful, smooth effect ✓
```
