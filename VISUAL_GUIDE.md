## Responsive Behavior Summary

### Image Heights
```
Desktop:     380px  (Large, detailed view)
Tablet:      280px  (Medium, more readable)
Mobile:      220px  (Compact, fits screen)
Extra Small: 180px  (Minimal, portrait-friendly)
```

### Heading Sizes
```
Desktop:     2rem       (32px)
Tablet:      1.6rem     (25.6px)
Mobile:      1.3rem     (20.8px)
Extra Small: 1.15rem    (18.4px)
```

### Button Behavior
```
Desktop:     Inline-flex (fits inline)
Tablet:      Full width with center align
Mobile:      Full width with center align
Extra Small: Full width with center align
```

### Layout
```
Desktop:     2 columns (Text left, Image right)
Tablet:      1 column (Text/Image stacked)
Mobile:      1 column (Text/Image stacked)
Extra Small: 1 column (Text/Image stacked)
```

## Interaction States

### Buttons (All breakpoints)
```
Normal:     Solid gradient, text visible
Hover:      Lifted up 2px, enhanced shadow
Mobile:     Full width, better tap target
```

### Images (Desktop/Tablet)
```
Normal:     Static, visible shadow
Hover:      Zoom 1.03x, smooth animation
Mobile:     No hover, only responsive
```

### Text
```
Normal:     Clear readable font
Mobile:     Reduced size but legible
Responsive: Font scales with viewport
```

## Accessibility Considerations

✅ **Touch-Friendly**
- All buttons: Minimum 44x44px tap target
- Proper spacing between interactive elements
- Full-width buttons on mobile (larger tap area)

✅ **Readable Text**
- Proper line-height ratios (1.3-1.8)
- Good color contrast
- Font sizes scale with screen size

✅ **Responsive Images**
- Always contain aspect ratio with `object-fit: cover`
- No distortion at any breakpoint
- Responsive sizing

✅ **Semantic HTML**
- Proper heading hierarchy
- Semantic list structure
- Meaningful alt text
