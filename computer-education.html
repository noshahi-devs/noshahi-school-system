The Skills Matrix

Four core pillars of our computer education curriculum — practical, modern, and future-ready.

Coding & Logic Building

Students learn computational thinking from scratch — starting with visual block-based coding and progressing to Python and JavaScript. Real problems, real solutions.

Python Scratch Logic Trees Algorithms

Robotics & AI Basics

Hands-on experiments with robotics kits and AI concepts. Students understand how machines "think," opening doors to engineering and data science careers.

AI Awareness Robotics Kits Automation Problem Solving

Web Development & Design

From writing their first HTML tag to styling a full page — students build real websites and learn UI fundamentals that matter in every modern profession.

HTML CSS UI Design Projects

Cyber Safety for Kids

Parents can relax — we teach children how to stay safe online. Topics include digital footprints, safe browsing, password hygiene, and responsible social media use.

Safe Browsing Privacy Digital Etiquette Passwords
